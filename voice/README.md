# voice/

Everything that defines how Relatively Normal sounds.

## What belongs here

- **Writing samples** — real pieces of my own writing (newsletter drafts, notes,
  captions, emails) that show the voice working. Raw and unedited is more useful
  than polished; the point is to capture how I actually write, not how I wish I
  wrote.
- **Style guide** — the do/don't list. Word choices, sentence rhythm, how much
  hedging is allowed, which jargon is banned, how to talk about bodies, budgets
  and brands.

## What doesn't belong here

Finished posts (those live in `content/posts/`) and the analytical frameworks
(those live in `frameworks/`). This folder is about *how* things are said, not
*what* is being said.

## Suggested files

- `style-guide.md` — the do/don't rules
- `samples/` — one file per writing sample, named `YYYY-MM-DD-slug.md`
